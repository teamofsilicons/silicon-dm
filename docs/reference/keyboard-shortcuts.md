# Keyboard shortcuts

Everything on the DM website can be done from the keyboard. These are the default keys; **Settings → Keyboard**
changes any of them (Enter to send and Shift+Enter for a new line follow **Settings → Sending** instead), and the
cheatsheet (`?`) always shows the keys you have now. This page is generated from the same list the website uses, so
it names every shortcut there is.

How the keys behave:

- **Where it works.** "Anywhere" shortcuts work on every page of the signed-in website. "In the message field" ones
  work while you type a message. "On a selected message" ones work when a message has the keyboard: press `⌘↑`
  (Ctrl+↑) in the message field to select the last message, then move with `↑`/`↓`.
- **Plain keys never fire while you type.** A single key such as `N`, `R` or `/` types the letter when you are in a
  text field; it is a shortcut only outside one.
- **Sequences.** "G then S" means: press G, let go, then press S.
- **Typing goes to the message field.** In a conversation, typing a letter that is not a shortcut starts your message.
- **Every action has a menu.** The menu key (or Shift+F10) on a selected message opens its menu, with every action by
  name and its keys, so you never need to remember one.
- **Changing keys.** Record new keys for any shortcut in **Settings → Keyboard**; the website warns when two shortcuts
  would share keys where both work. Your keys are kept in this browser.

## General

| --- | --- | --- | --- |
| `⌘K` | `Ctrl+K` | Command palette | Anywhere |
| `/` | `/` | Search conversations | Anywhere |
| `?` or `⌘/` | `?` or `Ctrl+/` | Keyboard shortcuts | Anywhere |
| `⌘.` | `Ctrl+.` | Show or hide the details panel | Anywhere |
